# docs/assets/diagrams

The site's diagrams are the milestone diagrams from the build, converted on 2026-10-17: their embedded colours, backgrounds and fixed sizes were removed so the site's stylesheet colours them for both themes; every id was prefixed with the diagram's name so two diagrams on one page do not share animation paths; the "Tested on ..." footers became figure captions; and text that described an unfinished build (such as "milestone 2 connects Gemma 4") was rewritten for the finished system.
