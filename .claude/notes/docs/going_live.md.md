# going_live.md

The plan's milestone 21 says "watching the first session together". The document makes that a sequence the user can follow on the first trading day: preflight before the open, the two dry-run checks that need a trading day (an order through UBI, and two traders wanting one stock), the switch to live, what to watch, and every way to stop, from /stop to the kill switch, with what each does to open positions.

It was written on Saturday 2026-10-17 with the service already running in dry_run, so Monday's scheduled checks and heartbeats run by themselves in dry run before the user switches.
