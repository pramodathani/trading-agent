# telegram_setup.md

Written for a user who has never used Telegram, as the plan requires, and kept in the repository so it can be followed again on another phone. It explains the moving parts in one paragraph first, then goes step by step: install, BotFather, token into .env, enable, doctor, pair, try, choose notifications, and what to do when something goes wrong.

It warns that look-alike BotFather accounts exist, that the token is a password not to be pasted into a chat with Claude, and that /kill is deliberately left out of the suggested command menu.

## Trader commands

`/traders`, `/create`, `/retire` and `/restore` were added with traders on demand. The table says that `/create` uses the default models and schedule and that the new trader may trade at once, because Telegram gives no form in which to set either.
