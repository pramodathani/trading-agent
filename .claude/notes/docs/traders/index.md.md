# docs/traders/index.md

The creating, retiring and states sections follow research-agent's `docs/analysts/index.md` from commit `4428bda`, adapted for traders.

The warning box about a new trader trading straight away is there because the user chose not to hold new traders back until their limits are approved, so the page that explains creation is where the consequence must be impossible to miss.

The `traders list` output was captured on 31 October 2026 from a gateway started from the feature branch on a copy of the live workspace, after a test trader was created and the scalper retired, so it shows both states; the mandates are shortened for the page.

"Moving from desks to traders" documents the automatic migration for anyone updating an older checkout; the trader migration's own note has the reasoning.
