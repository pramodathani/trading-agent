# page_catalogue.py

One list feeds the slash commands (/trading and the rest), the F2 page list and the Ctrl+P palette, so the three cannot disagree. The pages are in the web page's sidebar order.

`/skills` is also a trader command, which lists the trader's skills as text. In the terminal the page takes it, because the Skills page shows the same data with use counts and the hidden skills; the trader's command is left out of the menu so the menu does not offer two `/skills`.
