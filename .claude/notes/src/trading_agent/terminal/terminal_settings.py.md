# terminal_settings.py

The state folder follows the XDG base directory rule (`$XDG_STATE_HOME`, else `~/.local/state`), where per-user program state belongs, rather than the repository or the workspace, which the traders own.

`collapsed_cards` holds the side panel cards that are folded, by short name (`trader`, `model`, `context`, `funds`, `pnl`, `orders`, `tools`, `outputs`).
