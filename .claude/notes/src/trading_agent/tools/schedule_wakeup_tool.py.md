# schedule_wakeup_tool.py

A one-off agent job, in N minutes or at HH:MM India time (tomorrow if passed). Wake-ups are not limited to trading days, because a desk may want to come back to something on a holiday too; the description says so. Verified on 2026-10-17: Qwen scheduled a wake-up asking itself to reply NOTHING_TO_DO; one minute later it did, and the answer was marked silent.
