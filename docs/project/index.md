The code follows the conventions in the user's global instructions: Google-style docstrings on every class, method and function, names spelled out in full, one element per line in collections, class-based design, and no explanatory comments in code. The reasoning that would have been comments lives in `.claude/notes/`, one note per source file, mirroring the source tree.
